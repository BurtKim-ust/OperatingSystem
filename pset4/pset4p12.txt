1A. (i) Send SIGQUIT (signal 3) to the process
    (ii) Send SIGABRT (signal 6) to the process
    They both have a default action of terminating with coredump.

1B. We can remap the terminal's backspace to generate SIGQUIT instead.
Specifically, using the stty command would allow use to reassign the terminal's backspace.

1c. When there is a program that writes a large buffer to a pipe when SIGINT arrives. 
If the pipe is nearly full and only part of the data has been written, 
the signal handler interrupts the write. 
Without SA_RESTART flag set, write() returns with the partial byte count. 
The partial write "bug" will cause the program to lose track of how many bytes were 
actually written and wouldn't know where to resume writing, corrupting the data stream.

1D. The process is likely in an uninterruptible sleep state. 
This typically happens when the process is waiting for Disk I/O that isn't responding, 
which could be a failed NFS mount or bad disk problem. 
The kernel won't deliver signals to processes in this state until the I/O completes or times out.

1E. An IPI is a hardware interrupt sent from one CPU core to another in a multi-core system. 
When a process on CPU1 sends a signal to a process running on CPU2, 
the kernel uses an IPI to interrupt CPU2, forcing it to enter kernel mode.

With SA_NOMASK, signals are not blocked during handler execution. 
Segfault happened because before hh() finishes, another signal arrives, 
which causes hh() gets called again.
This happens many times with 50k signals arriving rapidly.

Fewer signals were received than with SA_NOMASK. With sa_flags=0, 
the signal is automatically blocked during handler execution. 
This prevents recursive handler invocations, making the handler 
run to completion before the next signal can be delivered.

This demonstrates that real-time signals (34-63) actually queue. 
Every single signal sent was received and counted. 
Unlike standard signals, real-time signals don't overwrite each
other when multiple instances are pending.
